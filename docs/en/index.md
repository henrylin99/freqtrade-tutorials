# Freqtrade Practical Tutorials

A complete tutorial series for learning Freqtrade quant trading from scratch — environment setup, data management, backtesting, hyperopt, risk management, up to small-capital live trading.

## Learning Path

| Stage | Lessons | Topics |
|------|------|------|
| Beginner | 1–5 | Intro, environment setup, core concepts, data management, first backtest |
| Intermediate | 6–15 | Performance analysis, multi-timeframe, pair selection, Hyperopt, scoring, portfolio |
| Practical | 16–24 | Realtime signals, Telegram, Web UI, dry run, order placement & monitoring |
| Advanced | 25–29 | Risk control, custom strategies, grid/HFT, FreqAI machine learning |
| Wrap-up | 30 | Summary and next steps |
