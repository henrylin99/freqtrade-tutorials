# Freqtrade 实战教程

从零开始学习 Freqtrade 量化交易的完整教程——覆盖环境搭建、数据管理、回测、参数优化、风险管理，直到小资金实盘。

## 学习路径

| 阶段 | 课程 | 内容 |
|------|------|------|
| 入门 | 第 1–5 课 | 简介、环境搭建、核心概念、数据管理、第一次回测 |
| 进阶 | 第 6–15 课 | 性能分析、多时间框架、选币、Hyperopt、评分体系、组合策略 |
| 实战 | 第 16–24 课 | 实时信号、Telegram、Web UI、Dry Run、下单与监控 |
| 高级 | 第 25–29 课 | 风控、自定义策略、网格/HFT、FreqAI 机器学习 |
| 总结 | 第 30 课 | 学习路径总结与下一步 |
