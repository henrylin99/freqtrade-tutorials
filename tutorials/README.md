### 第18课：Web UI 与 API 使用

**核心内容**：
- 启用 API Server：`"api_server": {"enabled": true, "listen_ip_address": "127.0.0.1", "listen_port": 8080}`
- 访问 FreqUI：http://localhost:8080
- 使用 REST API 查询数据
- 远程管理交易

**关键命令**：
```bash
freqtrade trade -c config.json --strategy Strategy001
# 然后访问 http://localhost:8080
```

## ⚠️ 风险警告

1. **量化交易有风险**：可能导致资金损失
2. **充分测试**：从模拟交易开始，至少2周
3. **小资金测试**：实盘从$100-$500开始
4. **持续学习**：市场在变化，策略需要调整
5. **风险管理**：永远是第一位的
